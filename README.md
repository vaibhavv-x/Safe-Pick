# Safe Pick

## Project Overview
Safe Pick is a user-friendly application designed to simplify the decision-making process for selecting various options. Whether it's choosing a restaurant, movie, or any kind of social activity, Safe Pick provides a seamless experience ensuring that your choices are informed and safe.

## Features
- **User-Friendly Interface:** Intuitive design that enhances user experience.
- **Variety of Options:** Supports various categories such as food, entertainment, and more.
- **Safe Recommendations:** Uses vetted sources to provide safe and reliable options.
- **User Feedback:** Allows users to provide feedback for continuous improvement.
- **Flexible Filtering:** Options to filter based on user preferences and restrictions.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Deployment:** AWS/GitHub Pages

## Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/vaibhavv-x/Safe-Pick.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd Safe-Pick
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Set up the environment:**
   Create a `.env` file in the root directory and configure it as needed.

5. **Run the application:**
   ```bash
   npm start
   ```

## Usage Guide
- **Accessing the App:** Open your browser and go to `http://localhost:3000` to access the application.
- **Selecting Options:** Use the interface to choose the category and make selections based on your preferences.
- **Providing Feedback:** After using the service, provide your feedback to help us improve.

For more detailed instructions, please refer to the documentation in the `docs` directory.
